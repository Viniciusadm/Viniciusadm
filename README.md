# Vinícius Alves de Morais

Full-stack developer from Brazil. I work mostly with TypeScript and React, Rust, PHP and Laravel, Kotlin with Jetpack Compose, and Godot for games.

| Project | What it is |
| --- | --- |
| [ribalta](https://github.com/Viniciusadm/ribalta) | A text language for themed visuals: a Rust compiler that also runs as WebAssembly, React renderers, editor support and an Android reader. |
| [rodada-web](https://github.com/Viniciusadm/rodada-web) / [rodada-api](https://github.com/Viniciusadm/rodada-api) | Live quizzes and games for groups: the host shows the match on a big screen and players join from their phones. React web app and Rust API. |
| [pitaco-web](https://github.com/Viniciusadm/pitaco-web) / [pitaco-api](https://github.com/Viniciusadm/pitaco-api) | Football prediction pools with score predictions and a ranking. React PWA and Rust API with axum and MySQL. |
| [eixo](https://github.com/Viniciusadm/eixo) | Viewer for a Google Maps Timeline export: the path on a map colored by travel mode, day by day. Rust API over SQLite and a web interface. |
| [dbusers](https://github.com/Viniciusadm/dbusers) | Desktop app for managing MySQL users and permissions without writing SQL, with an encrypted local vault. Rust and egui. |
| [pilha](https://github.com/Viniciusadm/pilha) | Local to-do list where free text is organized by an LLM and stored in SQLite, with a Cinnamon desklet. Rust. |
| [caixa](https://github.com/Viniciusadm/caixa) | CLI that uploads files to Google Drive and returns the download URL. Rust. |
| [calendar](https://github.com/Viniciusadm/calendar) | Android calendar and task app with recurrence, reminders and a home screen widget. Kotlin and Jetpack Compose. |
| [exercises](https://github.com/Viniciusadm/exercises) | Android workout tracker with live sessions, history, templates and progress per exercise. Kotlin and Jetpack Compose. |
| [flipbook-grabber](https://github.com/Viniciusadm/flipbook-grabber) | Chrome extension that saves AnyFlip publications as PDF or EPUB. TypeScript and React. |
| [rust-backend-template](https://github.com/Viniciusadm/rust-backend-template) | cargo-generate template for Rust HTTP backends with a hexagonal layout: axum, sqlx with MySQL, JWT and Argon2. |
